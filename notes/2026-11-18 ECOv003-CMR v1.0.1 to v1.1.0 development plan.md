# ECOv003-CMR v1.0.1 to v1.1.0 Development Plan

**Status:** Implemented (Ready for Pre-Release Verification)  
**Prepared:** 2026-11-18  
**Target repository:** `ECOSTRESS-Collection-3/ECOv003-CMR`  
**Target release:** `v1.1.0`

## 1. Objective

Resolve functional bugs and integration gaps identified in the `v1.0.1` codebase audit—specifically authenticated granule downloads, sequential multi-point sampling, CLI logging/error output, and repository hygiene—while maintaining full backward compatibility with the existing `ECOv003_CMR` public API.

## 2. Summary of Changes Included in v1.1.0

| Area | File(s) | Change Summary |
|---|---|---|
| **Authenticated Downloads** | `ECOv003_CMR/download_file.py`, `download_ECOSTRESS_granule_files.py`, `download_ECOSTRESS_granule.py`, `download_ECOSTRESS.py` | Added `session: Optional[requests.Session] = None` (defaulting to `setup_earthdata_session()`) and propagated it through all download entry points. |
| **CLI Error & Info Logging** | `ECOv003_CMR/download_ECOSTRESS.py`, `ECOSTRESS_CMR_search.py` | Replaced invalid `logger.info(..., file=sys.stderr)` with `logger.error()`, configured console logging in `main()`, added `-q/--quiet`, and printed results cleanly to stdout. |
| **Sequential Point Sampling** | `ECOv003_CMR/point_sampling.py` | Fixed loop indentation in `sample_points_over_date_range(..., max_workers=1)` so `stars_only_dates` and standalone `L3T_`/`L4T_` blocks run per point rather than leaking outside the loop. |
| **Multi-Day Download Date Propagation** | `ECOv003_CMR/download_ECOSTRESS.py` | Extracted each granule's actual acquisition date from its `GranuleID` instead of passing `start_date` for all granules. |
| **Progress Bar Import** | `ECOv003_CMR/download_file.py` | Switched `tqdm.notebook.tqdm` to `tqdm.auto.tqdm` to avoid Jupyter widget warnings in CLI runs. |
| **Parameter Spelling** | `ECOv003_CMR/download_ECOSTRESS_granule.py`, `download_ECOSTRESS_granule_files.py`, `README.md` | Standardized on `acquisition_date` while preserving `aquisition_date` as a backward-compatible alias. |
| **Packaging & Repo Hygiene** | `pyproject.toml`, `makefile`, root debug scripts | Bumped version to `1.1.0`, removed duplicate `pytest` dev dependency, removed dead `test-integration` Makefile target, and updated root debug scripts to Collection 3 (`2026` dates). |
